# Glossary

Common terms used throughout this guide.

| Term | Definition |
|---|---|
| **CAS** | Client Access Service — EZVIZ local authentication keys for LAN SDK |
| **Channel** | A video input source. `101` = ch1 main, `102` = ch1 sub. |
| **Device Serial** | Unique identifier for a camera/NVR in the EZVIZ system (e.g., D12345678) |
| **HCNetSDK** | Hikvision's native device SDK protocol used by EZVIZ for LAN access |
| **ISAPI** | Hikvision IP camera API standard for HTTP-based device control |
| **MPEG-PS** | MPEG Program Stream — container format used by EZVIZ local SDK |
| **MPEG-TS** | MPEG Transport Stream — standard container format for streaming |
| **NVR** | Network Video Recorder — records and manages multiple IP cameras |
| **ONVIF** | Open Network Video Interface Forum — standard protocol for IP cameras |
| **Pagelist** | EZVIZ API response containing all device metadata and capabilities |
| **P2P** | Peer-to-Peer — EZVIZ's NAT traversal for mobile app connectivity |
| **PTZ** | Pan-Tilt-Zoom — motorized camera movement control |
| **RF Session** | Refresh session ID used by EZVIZ for extended API sessions |
| **RTSP** | Real Time Streaming Protocol — standard for video stream delivery |
| **Session ID** | Authentication token returned by EZVIZ login API |
| **Sub stream** | Lower resolution/bitrate stream (`102`) for bandwidth-limited scenarios |
| **Main stream** | Full resolution stream (`101`) |
| **Verification Code** | Default password printed on the camera's physical label |
| **VTDU** | Video Transfer and Distribution Unit — EZVIZ cloud streaming auth tokens |
| **VTM** | Video Transfer Module — EZVIZ cloud streaming server selector |
| **WAN Live View** | EZVIZ app setting that enables RTSP over internet |
| **YS7** | EZVIZ/Hikvision open platform brand (萤石 / Ying Shi) |
